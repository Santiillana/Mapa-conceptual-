# Validación conceptual de TIC Explorer

Este documento sirve como lista de control para comparar el contenido del mapa con la especificación maestra. La validación de estructura no sustituye la revisión curricular por un docente.

- **TIC:** recursos tecnológicos que permiten crear, procesar, almacenar y comunicar información.
- **Equipos y herramientas TIC:** componentes físicos y dispositivos; distinguir entrada, procesamiento, salida y almacenamiento sin tratarlos como sinónimos.
- **Tipos de software:** clasificación funcional en software de sistema, software de aplicación y software de programación.
- **Servicios de Internet:** recursos en línea para navegación web, comunicación y colaboración; distinguirlos de los programas locales usados para acceder a ellos.
- **Licencias:** dimensión transversal que describe derechos y condiciones, no una función del software.
- **Precio y libertad:** software libre no significa necesariamente gratuito; precio y libertades de uso son conceptos diferentes.
- **Selección responsable:** considerar necesidad, compatibilidad, seguridad, accesibilidad, privacidad, costo total y soporte.
